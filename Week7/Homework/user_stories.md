# User Stories
## Case
'Add to Cart → Purchase' conversion by region in real-time

User Stories follow: "As a [role], I want [feature] so that [benefit]"

## User Story 1
As the Japan e-commerce regional manager, I want purchases to be logged in the local currency, the Yen, so that I can understand exactly what the sites cashflow within the region without the need for after-the fact conversion that may miss real-time conversion rates, skewing the data.

## User Story 2
As a thrid-party partner I would like the site to record how much of my profits they take off each item, in additon to automatic warehouse tracking, so that I know exactly what's being stored in my warehouse by the start-up, and what percentage of profit I'm getting per sale.

## User Story 3
As a customer of the site I would like that all items carried through from adding to the cart are properly converted into the correct currency at purchase, so that my bank won't charge me extra conversion rates.
